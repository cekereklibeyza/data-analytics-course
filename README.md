# Data Analytics Course

This repo contains the code and notebooks I've worked on for my Data Analytics course. Notebooks were prepared and run on Google Colab.

## Contents

| Notebook | Topic | Description |
|---|---|---|
| `veri_analitigi_adaboost_xgboost.ipynb` | AdaBoost vs XGBoost — Credit Card Fraud Detection | Comparing AdaBoost and XGBoost on a real-world, highly imbalanced dataset (Credit Card Fraud Detection) |

## How to run

This notebook was built for Google Colab. To run it:

1. Open the file in [Google Colab](https://colab.research.google.com) (use the "Open in Colab" button on the file's GitHub page, or download and upload it to Colab manually).
2. Upload the dataset (`creditcard.csv`) to Google Drive and mount Drive in the notebook.
3. Run the cells in order.
