# Data Analytics Course

This repo contains the code and notebooks I've worked on for my Data Analytics course. Notebooks were prepared and run on Google Colab.

## Contents

| Notebook | Topic | Description |
|---|---|---|
| `adaboost_vs_xgboost_credit_card_fraud.ipynb` | AdaBoost vs XGBoost — Credit Card Fraud Detection | Comparing AdaBoost and XGBoost on a real-world, highly imbalanced dataset (Credit Card Fraud Detection) |
| `logistic_regression_diabetes.ipynb` | Logistic Regression — Diabetes Health Indicators | Multi-class logistic regression predicting diabetes status (no diabetes / prediabetes / diabetes) from health survey indicators |

## How to run

These notebooks were built for Google Colab. To run one:

1. Open the file in [Google Colab](https://colab.research.google.com) (use the "Open in Colab" button on the file's GitHub page, or download and upload it to Colab manually).
2. Upload the notebook's dataset (`creditcard.csv` or `diabetes_012_health_indicators_BRFSS2015.csv`) to Google Drive and mount Drive in the notebook.
3. Run the cells in order.
